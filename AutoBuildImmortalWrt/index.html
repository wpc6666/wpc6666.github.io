AutoBuildImmortalWrt

基于 GitHub Actions 的 ImmortalWrt 固件自动构建工作流。一键产出带 Docker、可自定义固件大小的 OpenWrt / ImmortalWrt 固件。

GPL-3.0GitHub ActionsFork刷机有风险
GitHub 仓库 上游原项目

这是什么

一个跑在 GitHub Actions 上的固件编译工作流。你在网页上点一下 Run workflow，云端自动编译出 ImmortalWrt 固件，编译完成后到 Releases 下载刷机。不需要本地装编译环境。

预装 Docker

填宽带账号密码，开机即拨号
云端编译
不占本地资源，约 2–4 小时

使用步骤

  1. Fork 仓库 — 到你自己的账号下
  2. 启用 Actions — 在 Actions 标签页点 I understand my workflows, go ahead and enable them
  3. 运行工作流 — 左侧选平台，右侧 Run workflow，按需勾选 Docker / 拨号 / 固件大小
  4. 下载固件 — 编译完成后到 Releases 页面下载

默认网络属性（必读）

设备类型默认行为
单网口DHCP 模式，IP 由上级路由分配
多网口eth0 为 WAN（DHCP），其余 LAN，管理地址 192.168.100.1
勾选拨号WAN 口走 pppoe 拨号
旁路由用户注意：不要改配置文件里的默认 IP 来设置旁路。旁路由应走单网口模式，先接上级路由，在上级路由后台查到它被分配的 IP，再访问配置。

风险提示

刷机有变砖风险。请先确认机型与固件严格对应，准备好救砖手段（TFTP 恢复 / 串口 / 官方恢复工具），不要在主力设备上首次尝试。
